# Site components

Our own building blocks for AVProgress. Each one is assembled from BoardUI
pieces (`../base`, `../application`) and BoardUI's semantic Tailwind classes.

The sibling folders `base/`, `application/` and `foundations/` are BoardUI's
source, copied in unchanged from https://github.com/BoardUI/boardui (MIT).
Don't edit those; to update them, copy in the newer file. Put anything
AVProgress-specific here instead.
